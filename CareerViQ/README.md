# CareerViQ

Minimal React Native app scaffold built with Expo.

## Run locally

```bash
npm install
npx expo start
```

Use Expo Go to scan the QR code, or press `a` to launch an Android emulator.

## Structure

- `App.js` — starter screen showing the CareerViQ app name
- `app.json` — Expo app metadata
- `index.js` — app entry point
